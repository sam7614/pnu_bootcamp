# Ⅱ장 재정투자 실적 초기 초안

- 상태: 계획자료 기반 구조 초안
- 검토 상태: 보류
- 사용 제한: 실제 집행 원장·정산자료와 승인 변경예산을 확보하기 전 최종 제출본에 통합하지 않음
- 금액 단위: 백만원

## 공통 주의사항

1. 아래 계획값은 `1차 수정본 0.2`의 계획 후보이며 변경 승인 공문이 없어 확정 계획예산이 아님.
2. 실집행액·집행률·잔액은 원자료 미확보로 숫자를 기재하지 않음.
3. 2025년 공식 양식의 `2026년 2월 말` 기준을 2026년 사업에 그대로 적용하지 않음. 2026년 협약기간은 2026-03-01~2027-02-28이나 보고 기준일은 최신 제출 공문으로 확정해야 함.
4. 아래 출처 ID는 팀 2 임시 분석 ID임. 총괄의 정식 Source ID 등록 후 교체함.

### 계획 부분 초안

□ 산업 수요 기반 AI 교육을 위한 인력·교육환경·프로그램 중심 재정투자 계획

◦ 1차년도 사업비는 전담 운영체계 구축, 실습 인프라 확보, 몰입형 교육과 기업 연계 프로그램 운영, 학생 지원을 주요 투자축으로 편성할 계획임.

- 수정 사업계획서 후보의 국고지원금 총액은 1,425.000이며, 직접비 1,353.750과 간접비 71.250으로 구성되어 있음. [근거: T2-SRC-03 / PDF p.132]
- 직접비는 인건비 383.910, 학생인건비 16.000, 연구시설·장비 구입·설치비 285.750, 연구재료비 26.000, 연구활동비 계산 소계 642.090으로 계획되어 있음. 다만 사업계획서 내부 합계·비율 불일치와 변경 승인 여부를 확인해야 함. [근거: T2-SRC-03 / PDF p.132~135]

□ 사업추진실적과 집행의 연계성 검토 보류

◦ 현재 확보된 자료는 협약과 계획 후보뿐이며, 실제 집행 원장과 추진실적 증빙이 없어 재정투자 우선순위에 따른 집행 적절성을 판정할 수 없음.

◦ 수정 사업계획서 후보는 부산시가 2026년부터 2030년까지 매년 71.000, 총 355.000의 현금을 부담하는 계획을 제시하고 있음. [근거: T2-SRC-03 / PDF p.120, p.149]

- 현재 현금 납입 확약서 원본, 실제 입금내역, 재원별 회계원장과 지출 증빙이 없어 확보액과 집행실적을 확정할 수 없음.

### 본문 초안

□ 이월금 해당 여부 확인 필요

◦ 현재 확보된 협약서와 수정 사업계획서에서는 전년도 이월 승인액과 이월금 집행내역을 확인할 수 없음.

- 1차년도라는 이유만으로 이월액을 임의로 0으로 기재하지 않음.
- 이월 승인 공문과 별도 원장이 없고 재정 담당의 이월 없음 확인이 확보되는 경우에만 `해당 없음`으로 처리함.
- 이월금이 확인되면 승인액, 승인 사유·조건, 실집행액, 집행률, 잔액과 승인 조건 준수 여부를 별도 표로 작성함.

## 팀장 검토 의견

- 공식 작성방법과 표 구조는 반영하였음.
- 계획과 실적을 분리하였고 실집행액을 임의 생성하지 않았음.
- 사업계획서 내부 불일치가 해소되지 않았으며 집행·정산자료가 없어 모든 목차의 최종 승인 상태는 `보류`임.
- 승인 예산, RCMS 원장, 부산시 입금·집행 자료, 이월 해당 여부 자료를 확보한 뒤 표 계산과 본문을 전면 재검증해야 함.
