# 성과지표 정의서

> 상태: 초기 구조. 공식 성과지표 정의서와 실적조사표를 확보한 뒤 작성합니다. 확인되지 않은 값은 입력하지 않습니다.

## 공통 기록 항목

- 지표 ID와 공식 지표명
- 공식 정의와 인정·제외 기준
- 해당연차 또는 누적 구분
- 단위
- 분자와 분모
- 공식 산식과 반올림 방식
- 산정 기준일과 대상기간
- 목표값의 승인 근거
- 실적값의 Source ID와 Evidence ID
- 중복 제거 방법
- 관련 보고서 목차

## 검증 대상 지표

- 전담인력 수
- 제도개선 건수
- 참여기업 수
- 참여교원
- 교육프로그램 운영
- 양성인원과 중·고급 이수자 비율
- 배출인원
- 취업인원·취업률·연계취업률
- 학생·기업 만족도
- 자율지표
- 재정집행률

## 정의 확정 전 금지사항

- 전년도 또는 타 사업의 정의를 임의로 적용하지 않음.
- 사람 수와 참여 건수를 혼용하지 않음.
- 동일인을 프로그램별로 중복 합산하지 않음.
- 예정·진행중 실적을 완료 실적으로 집계하지 않음.
