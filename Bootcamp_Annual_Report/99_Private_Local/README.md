# 99_Private_Local 사용 안내

이 폴더는 Git에 올리면 안 되는 개인정보·민감정보·상세 재정정보의 로컬 보관용입니다.

보관 예시:

- 학생·교원·직원 원본 명단
- 주민등록번호, 연락처, 주소가 포함된 문서
- 취업 확인 원본과 개인별 이력
- 계좌번호, 급여, 지출결의, 거래처 정보가 포함된 문서
- 공개 전 보고서와 내부 검토자료 중 별도 보안이 필요한 파일

주의사항:

- 원본을 채팅에 그대로 붙여 넣지 않습니다.
- 공개용 산출물에는 필요한 최소 정보와 집계값만 사용합니다.
- 이 폴더의 파일을 외부로 복사·업로드하기 전 사용자 승인을 받습니다.
- `README.md`를 제외한 이 폴더의 내용은 `.gitignore`로 Git 추적에서 제외됩니다.
