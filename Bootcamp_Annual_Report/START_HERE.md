# 처음 시작하는 안내서

## 1. 이 프로젝트의 목적

이 폴더는 부산대학교 첨단산업 인재양성 부트캠프사업 1차년도 연차실적보고서를 준비하기 위한 전용 작업공간입니다. 공식 보고서 양식, 사업계획, 실제 운영실적, 재정자료, 성과지표, 증빙자료를 서로 연결하여 정확하고 검증 가능한 보고서를 만드는 것이 목표입니다.

현재는 **프로젝트 구조와 관리체계만 준비한 초기 단계**입니다. 확인되지 않은 사업 실적은 작성하지 않았습니다.

## 2. 전체 폴더 구조와 역할

```text
Bootcamp_Annual_Report/
├── 00_Project_Control/        공식 양식, 작성 참고자료, 지침, 체크리스트
├── 01_Source_Documents/       사업 원본 자료(기본 Git 제외)
├── 02_Team1_Implementation/   Ⅰ장 사업 추진 실적
├── 03_Team2_Finance/          Ⅱ장 재정투자 실적
├── 04_Team3_Performance/      Ⅲ장 사업성과 달성도
├── 05_Team4_Evidence/         증빙자료 등록·선정·검토
├── 06_Shared_Data/            공통 원장과 검증된 마스터 수치
├── 07_Integrated_Report/      통합 초안, 편집본, 검토본, 최종 제출본
├── 08_Review_and_History/     검토 결과, 변경 이력, 이슈
└── 99_Private_Local/          개인정보·민감정보 로컬 보관(Git 제외)
```

### 자료 폴더를 쉽게 고르는 법

- 분류를 알고 있으면 `01_Source_Documents/01~15`의 해당 폴더에 넣습니다.
- 어디에 넣어야 할지 모르겠으면 `01_Source_Documents/00_Inbox_Upload_Here/`에 넣습니다.
- 개인정보, 인사 원본, 취업증빙, 상세 재정증빙처럼 민감한 파일은 `99_Private_Local/`에 먼저 보관하고 Codex에게 안전한 처리 방법을 요청합니다.
- 원본 파일은 Codex가 사용자 승인 없이 삭제하거나 이동하지 않습니다.

## 3. 가장 먼저 준비할 문서

1. 해당 연도 공식 연차실적보고서 양식 PDF
2. `문장구조 및 기술방법.pdf`
3. 최초 승인 사업계획서 전체
4. 승인된 변경 사업계획서와 변경 승인 공문
5. 사업협약서, 운영지침, 제출 공문
6. 공식 실적조사표.xlsx와 성과지표 정의서
7. 교육프로그램·위원회·기업협력 등 운영실적 자료
8. 예산, 변경예산, 집행, 정산 자료
9. 성과지표별 증빙과 행사 사진

자세한 목록과 저장 위치는 `00_Project_Control/04_Guidelines_and_Checklists/REQUIRED_DOCUMENTS.md`에서 확인합니다.

## 4. 자료 넣는 방법

1. 원본은 수정하지 말고 그대로 보관합니다.
2. 파일이 어느 범주인지 확실하면 알맞은 하위 폴더에 복사합니다.
3. 잘 모르겠으면 Inbox 폴더에 복사합니다.
4. 개인정보가 포함되어 있으면 파일명이나 채팅에 주민등록번호, 계좌번호 등을 노출하지 않습니다.
5. 파일을 모두 넣은 뒤 아래의 “다음 단계 명령”을 Codex에 입력합니다.

## 5. 권장 파일명

권장 형식은 다음과 같습니다.

```text
YYYYMMDD_자료구분_세부명_작성기관_버전.확장자
```

예시:

```text
20261031_교육프로그램_중급과정운영결과_부산대학교_v1.pdf
20261101_재정_국고지원금집행현황_부산대학교_확정.xlsx
```

- 날짜를 모르면 `날짜미상`으로 표시합니다.
- `최종`, `진짜최종`을 반복하기보다 `v1`, `v2`, `확정`을 사용합니다.
- 원본 파일명은 분석 전 임의로 바꾸지 않아도 됩니다.

## 6. 현재 진행 상황 확인

- 전체 상태: 루트의 `PROJECT_STATUS.md`
- 준비자료 목록: `REQUIRED_DOCUMENTS.md`
- 자료 등록 상태: `06_Shared_Data/01_Registries/file_intake.csv`
- 쟁점과 누락: `06_Shared_Data/01_Registries/issues.csv`
- 변경 이력: `08_Review_and_History/03_Change_History/change_log.md`

## 7. 자료를 넣은 후 Codex에 입력할 명령

아래 문장을 그대로 입력하면 됩니다.

> 프로젝트 폴더에 자료를 추가했어. 전체 파일을 확인하고 공식 작성방법과 문장기술 기준에 따라 목차별 자료를 분류한 뒤, 누락 자료 목록과 보고서 작성계획을 만들어줘.

그 다음 Codex는 신규 파일 탐색, 문서 종류·기준기간 확인, Source ID 등록, 목차 연결, 중복·개정본 확인, 누락 자료 정리 순서로 작업합니다.
