## 4. 가장 중요한 미해결 위험

1. 확보 양식은 2025년 실적기간 예시이고 사업은 2026.03.~2027.02.이므로 적용 양식·기준일을 확정해야 함.
2. 수정 사업계획서 0.2의 변경 승인 공문이 없어 목표·예산의 승인 효력이 미확정임.
3. 성과지표 XLSX는 0.1 내부본이며 현재/예상 혼합, 요약-상세 불일치, 중·고급·취업·만족도 산식 문제가 있음.
4. 운영·학생·졸업·취업·재정의 직접 증빙이 대부분 없음.
5. 계획값·예상값을 실적으로 전환하지 않았으므로 요약 달성률·Ⅱ장 집행률·Ⅲ장 실적값은 아직 공란이어야 함.
