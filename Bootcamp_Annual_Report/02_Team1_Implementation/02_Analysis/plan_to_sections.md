### 협약으로 확정 가능한 공통 전제

- 총 사업기간은 2026.03.01.~2031.02.28.이며, 당해연도 사업기간은 2026.03.01.~2027.02.28.임. `[협약 p.1, p.5]`
- 당해연도 협약 사업비는 1,425,000천원으로 기재되어 있음. 다만 이는 협약액이며 집행실적이 아님. `[협약 p.1, p.5]`
- 대학·산학협력단·사업단장은 협약과 관계 규정에 따라 사업을 수행하고, 사업계획서 작성·제출, 사업비 집행·관리, 실적 보고 등의 책임을 부담함. `[협약 p.2~4, p.6~8]`

## 4. 현재 자료로 확정 가능한 계획정보와 확정 불가능한 실적

1. 협약·사업계획상 사업기간, 당해연도 기간, 협약 사업비
2. C.O.R.E 전략, PNU-ACE, 7대 트랙, 초·중·고급 및 교과형·몰입형 교육구조

4. 사업계획서 성과관리계획에 기재된 1차년도 목표값
5. 학사·교원제도 개선안과 계획 일정
6. 기업·지자체·외부인프라·취업지원의 계획상 참여방식

### 현재 자료만으로 확정 불가능한 실적

- 실제 임용·채용·위원회 개최·규정 개정·학점 인정·교과 개설 여부
- 기업 참여의향서 기준 공식 참여기업 수와 공동개발·공동운영·현장실습·채용 활동
- 시설·장비의 구매·검수·공사완료·교육 활용
- 과정별 모집·수강·출결·평가·이수·인증·장학 지급
- 양성·배출·취업·연계취업·참여기업 취업 및 만족도 실적
- 부산시 부담금과 민간투자지원금의 실제 입금·집행·활용성과
- 자체평가 결과, 문제점, 개선조치와 환류 완료 여부

## 5. 작성 시 강제 적용할 원칙

- 계획은 `계획함/추진 예정임`, 실제 이행은 원자료 확인 후에만 `운영함/완료함`으로 구분함.
- 공식 양식의 양성·배출·취업 정의를 우선하고, 사업계획서 내 다른 표현으로 공식 지표 정의를 바꾸지 않음.
- 2026.03.01.~2027.02.28. 전체를 당연히 완료된 실적기간으로 간주하지 않으며, 각 자료의 기준일을 별도 표시함.
- 1차년도 목표값은 실적값이 아니며 달성률 계산에 직접 전용하지 않음.
- 실제 수치 사용 전 `master_metrics.csv`의 검증·승인 값을 확인함.
