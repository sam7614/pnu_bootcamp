# 표 구성 규칙 및 작업용 템플릿 — 확정본

공식 양식의 지정 표가 항상 우선한다. 아래 표는 초안 작성과 누락 점검용이며, 값은 공식 증빙 검증 후에만 입력한다.

## 공통 서식

- 표 제목 위에는 절 번호와 핵심 메시지를 둔다.
- 머리글은 진한 남색·흰 글자, 분류 셀은 연한 청색/회색, 테두리는 가는 청색을 적용한다.
- 단위는 표 오른쪽 위, 기준기간·출처·증빙은 표 아래에 둔다.
- 숫자는 오른쪽 정렬, 문장은 왼쪽 정렬, 상태는 가운데 정렬한다.
- 표가 페이지를 넘으면 머리글 행을 반복한다.

## 검산 규칙

- `잔액 = 계획 또는 승인 예산 - 실집행액`(적용 기준을 표에 명시)
- `집행률 = 실집행액 ÷ 적용 예산 × 100`
- `달성률 = 실적값 ÷ 목표값 × 100`을 원칙으로 하되 공식 지표 정의가 다르면 정의서를 우선함
- 전체 달성률은 공식 양식이 요구하는 개별 성과지표 달성률의 평균 방식과 상한 적용 여부를 제출기관에 확인함
- 반올림 자리, 0·공란·해당없음 처리 기준을 표 주석에 명시함
