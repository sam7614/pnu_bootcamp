# 사용자가 준비할 추가자료 — 우선순위

기준일: 2026-11-06  
원칙: 가능한 한 원본 파일, 최종 승인본, 기준일이 표시된 집계본을 제공한다. 개인정보·재정 원자료는 현재 지정된 보안 폴더에 두고 외부 공유 전에 비식별한다.
