## 6. 증빙 승인 게이트

증빙은 다음 순서를 모두 통과한 뒤에만 `승인`함.

1. 원본 파일 열림·체크섬·발행기관·일자·버전·승인 상태 확인
2. 보고 대상 기간·기준일·대상·단위·분모·분자 확인
3. 본문 주장/수치와 원본 페이지·시트·셀의 직접 대조
4. 공통 수치의 `master_metrics.csv` 승인값과 일치 확인
5. 개인정보·재정 민감정보 비식별 및 별도 검토
6. `본문 → reference_registry → Source ID → Evidence ID → 선정 사본` 정방향 추적
7. `Evidence ID → 입증 주장 → 본문 파일·표` 역방향 추적
8. 최종 통합 PDF에서 실제 증빙 페이지·목차·본문 참조 재확인

현재는 1단계의 파일 존재·일부 체크섬 확인만 완료되었고, 승인 가능한 Evidence ID는 없음.
