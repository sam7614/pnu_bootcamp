## 5. 다음 작업 순서

1. 총괄이 최신 양식·제출 공문·최초/변경 승인 계획·공식 실적조사표를 확보하여 적용 기준을 잠금.
2. 완료된 Source 등록을 기준으로 신규 원본 반입 시 중복·개정·보안등급을 갱신함.
3. T4-01~04가 `evidence_gap_report.md`의 P0 자료를 보안 상태로 접수하고 원본의 발행·일자·기간·승인을 확인함.
4. 팀 3과 함께 XLSX의 공식 산식·기준일·중복·상세 원자료를 검산하고 승인된 값만 `master_metrics.csv`에 잠금.
5. 팀 1~3의 주요 주장·표·수치를 `reference_registry.csv`에 등록하고 필요한 최소 페이지·시트 단위로 Evidence ID를 선정함.
6. 개인정보·재정정보를 비식별한 제출 후보 사본을 별도 생성하고 원본과 입증력이 유지되는지 이중 검토함.
7. 통합본 편집 후 본문 페이지, 증빙 목차, Evidence ID, 최종 증빙 페이지를 전수 대조함.

## 6. 팀장 4 검토 결론

- 파일 탐색, 완전 중복 판정, 원천자료 효력 구분, 전체 목차별 필수 증빙과 P0/P1/P2 격차 분석을 완료함.
- 등록·선정·비식별·본문 연결·최종 페이지 확인은 실제 원자료와 총괄 원장 갱신 전이므로 완료로 기록하지 않음.
- Source 7건과 중복경로 1건은 등록되었으나, 승인 Evidence ID·공통 실적값·제출용 증빙 사본은 없음.
- 팀 1~3의 계획 기반 초안은 유지할 수 있으나, 실적 문장·달성률·집행률·우수사례는 P0 증빙 확보와 교차검증 후에만 확정함.
