# 원천자료·증빙 후보 분석

- 분석일: 2026-11-06
- 담당: 팀장 4(증빙·품질관리)
- 상태: 파일 탐색·중복 판정·증빙 적합성 사전분석 완료 / 통합 단계 Source 등록 완료 / Evidence ID 승인 미착수
- 적용 원칙: 파일이 존재한다는 사실과 보고서 실적을 입증한다는 판단을 구분함. 계획서·협약·내부 관리표를 실제 이행 증빙으로 대체하지 않음.

## 1. 점검 범위와 판정 기준

프로젝트 전체를 탐색하고 사용자 제공 원본 후보, 팀 1~3 작업 산출물, 공통 원장, 임시 추출물을 구분하여 점검함. 사용자 제공 원본 후보는 8개 경로이며, 사업계획서의 완전 중복 1개를 제외하면 SHA-256 기준 7개 고유 파일임. 팀 산출물과 `tmp/`의 텍스트·이미지·JSON은 분석 과정에서 생성된 작업물로 원천자료 또는 최종 증빙으로 등록하지 않음.

현재 판정 용어는 다음과 같이 사용함.

| 용어 | 의미 |
|---|---|
| 확보 | 파일 경로와 열림 여부를 확인한 상태. 공식성·적용연차·내용 정확성을 보장하지 않음. |
| 등록 | `source_registry.csv`에 Source ID와 메타데이터를 기록한 상태. 분석 후 통합 단계에서 7개 Source와 중복경로 1개를 등록함. |
| 검증 | 발행기관·승인상태·버전·기준기간·수치·체크섬을 원본과 대조한 상태. |
| 선정 | 특정 주장·수치를 입증할 최소 페이지·시트에 Evidence ID를 부여한 상태. 현재 0건임. |
| 승인 | 입증력·개인정보·상호추적·최종 페이지까지 팀장 검토를 통과한 상태. 현재 0건임. |

아래 `CAND-*` 표기는 분석 편의를 위한 후보 번호이며 공식 Source ID가 아님.

## 6. 중복·버전 관리 결정안

1. 완전 중복인 수정 사업계획서 두 경로는 하나의 Source ID로 관리하고 `notes`에 두 경로와 동일 SHA-256을 기록함.
2. 중복 파일을 사용자 승인 없이 삭제·이동하지 않음. 원본 폴더의 파일을 기준 위치 후보로 삼고 루트 파일은 중복 위치로 표기함.
3. 공식 양식 HWP와 PDF는 내용 동등성이 검증될 때까지 각각 후보로 유지함. PDF는 시각 검토 기준본, HWP는 편집 후보로 사용함.
4. 문장구조 PDF와 SW중심대학 HWPX는 다른 사업의 참고자료로 분리함. 본 사업 Source/Evidence 체계에는 실적 원천으로 등록하지 않음.
5. 수정 사업계획서 0.2는 변경 승인 공문을 확보할 때까지 `승인 확인 필요`로 표시함. 최초 승인본과 승인된 개정본은 각각 Source ID를 부여하고 `revision_of_source_id`로 연결함.
6. 성과지표 XLSX 0.1은 새 최종본으로 덮어쓰지 않고 중간 버전으로 보존함. 최종본 또는 공식 제출본은 새 Source ID를 부여함.

## 8. 현재 결론

- 사용자 제공 원본 후보는 계획·양식·협약·내부 관리표 중심이며, 실제 운영·재정·성과를 직접 입증하는 승인 가능한 증빙 묶음은 아직 없음.
- 통합 단계에서 Source 7건과 중복경로 1건은 등록되었으나, Evidence ID·승인 수치·검토 승인 기록은 0건임.
- 계획 부분과 빈 구조 초안은 작성 가능하나 실적값·달성률·집행률·정성 성과를 확정할 수 없음.
- 최우선 과제는 2026년 적용 양식·제출 공문·변경 승인문서·공식 실적조사표를 확보하고, 핵심 지표와 재정 집행의 원자료를 보안 상태로 접수하는 것임.
